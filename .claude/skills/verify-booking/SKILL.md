# 予約システム実機確認チェックリスト

ユニットテストとビルドが通っても、以下はデプロイ環境・LINE実機・複数端末で
のみ確認できる。tendledgeのverify-tauriスキルと同じ運用: **機能を追加したら
対応するチェック項目をここに追記する**。

## ダブルブッキング防止(ADR-004)

- [ ] 2つのブラウザで同じスタッフ・同じ時間帯の予約画面を開き、ほぼ同時に
      確定 → 片方だけ成功し、もう片方に「その枠は埋まりました」が表示される
- [ ] キャンセル済み予約と同じ枠に新規予約できる(WHERE status='confirmed' の確認)
- [ ] 所要時間の長いメニュー(例: 180分)が、途中の時間帯の別予約と重複できない
- [ ] スタッフの休憩・予約不可時間に重なる枠が客側に表示されない

## LIFF・LINEログイン(ADR-003)

- [ ] LINEアプリのリッチメニューから予約画面が開き、ログイン操作なしで
      本人が特定されている(初回は名前・電話番号の入力画面が出る)
- [ ] 2回目以降の予約で個人情報の入力がスキップされる
- [ ] マイ予約に自分の予約だけが表示される(他人の予約が見えない)

## 通知(ADR-002)

- [ ] 予約確定時にLINEトークへ確認が届く
- [ ] 前日リマインドが指定時刻に届く(Cron Triggerの動作確認)
- [ ] 管理画面のプッシュ送信数カウンタが送信のたびに増える

## 管理画面(ADR-005)

- [ ] 未ログイン状態で /admin 配下のURLを直接開くとログイン画面に飛ばされる
- [ ] スタッフ権限でオーナー専用機能(スタッフ管理・メニュー管理)が操作できない
- [ ] 代行登録した電話予約が客側の空き枠計算に即時反映される

## レスポンシブ(ADR-005)

- [ ] 管理画面をスマホ幅で開く → カレンダーが1スタッフ切替またはリスト表示に
      切り替わり、横スクロールが発生しない
- [ ] 客側の全画面がスマホ縦(LINE内ブラウザ)で崩れない

## データ設定(ADR-007)

- [ ] メニュー・カテゴリ・営業時間を管理画面から変更 → コード変更なしで
      客側の表示・空き枠計算に反映される
