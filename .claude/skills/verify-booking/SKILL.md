# 予約システム実機確認チェックリスト

ユニットテストとビルドが通っても、以下はデプロイ環境・LINE実機・複数端末で
のみ確認できる。tendledgeのverify-tauriスキルと同じ運用: **機能を追加したら
対応するチェック項目をここに追記する**。

## ダブルブッキング防止(ADR-004)

- [ ] 2つのブラウザで同じスタッフ・同じ時間帯の予約画面を開き、ほぼ同時に
      確定 → 片方だけ成功し、もう片方に「その枠は埋まりました」が表示される
- [ ] キャンセル済み予約と同じ枠に新規予約できる(WHERE status='confirmed' の確認)
- [ ] 所要時間の長いメニュー(例: 180分)が、途中の時間帯の別予約と重複できない
- [ ] スタッフの休憩・予約不可時間に重なる枠が客側に表示されない

## 客側予約フロー(M2)

- [ ] 日時選択で、埋まっている時刻が取り消し線+グレーで表示され押せない。
      勤務時間・所要時間の関係で確保できない時刻はそもそも表示されない
- [ ] 直前締切(開始60分前)を過ぎた当日の枠、受付期間(30日先)を超える日付が
      選択できない(いずれも salon_settings の値。変更したら反映されること)
- [ ] 「どちらでも」で予約 → 空いているスタッフのうち表示順が小さい方
      (実質オーナー)に割り当てられる。オーナーが埋まっている枠では
      もう一方に割り当てられる
- [ ] 初回予約で customers に1行だけ作成され、ご要望欄が reservations.note に、
      メニューのスナップショット(名前・料金・所要時間)が reservation_menus に入る
- [ ] メニュー選択でカテゴリ見出しに説明文(menu_categories.description)が表示される
- [ ] 完了画面に「確認のメッセージをLINEにお送りしました」が**表示されない**(M5まで)

## マイ予約・キャンセル・変更(M3)

- [ ] **変更の競合ロールバック**: 客Aが変更の確認画面まで進んだ状態で、別ブラウザの
      客Bが変更先と同じ枠を先に予約 → 客Aの変更確定は「その枠は埋まりました」になり、
      **客Aの元の予約が confirmed のまま無傷で残っている**(DBで status を確認)
- [ ] キャンセル直後に同じ枠が別客の日時選択に「空き」として出る
- [ ] 変更で「同じ枠のままメニューだけ追加」「同じスタッフで30分ずらし」ができる
      (自分の旧予約の枠が「埋まり」表示にならない)
- [ ] 締切(開始 cancel_deadline_minutes 前)を過ぎた予約は変更・キャンセルボタンが
      無効化され「お店に直接ご連絡ください」が表示される。salon_settings の値を
      変えると反映される
- [ ] Server Action を直接叩いて他人の予約IDのキャンセル・変更を試みる → 拒否され、
      対象予約に変化がない(RPC内の本人確認)
- [ ] LINE実機: リッチメニューの「マイ予約」ボタンから /my が直接開く(M6デプロイ後)

## LIFF・LINEログイン(ADR-003)

- [ ] LINEアプリのリッチメニューから予約画面が開き、ログイン操作なしで
      本人が特定されている(初回は名前・電話番号の入力画面が出る)
- [ ] 2回目以降の予約で個人情報の入力がスキップされる
- [ ] マイ予約に自分の予約だけが表示される(他人の予約が見えない)

## 通知(ADR-002)

- [ ] 予約確定時にLINEトークへ確認が届く
- [ ] 前日リマインドが指定時刻に届く(Cron Triggerの動作確認)
- [ ] 管理画面のプッシュ送信数カウンタが送信のたびに増える

## 管理画面コア(M4・ADR-005)

### 認証・アクセス制御

- [ ] 未ログイン状態で /admin 配下のURL(/admin・/admin/reservations/new など)を
      直接開くとログイン画面に飛ばされる。ログアウト後も同様
- [ ] 誤ったメール/パスワードで「メールアドレスまたはパスワードが違います」が出る
- [ ] **anonキーでのアクセス拒否**: anon キー(公開キー)で各テーブルを直接読み書き
      しようとすると、RLSポリシーが無いため全拒否される(SQL/REST で確認)
- [ ] **セルフサインアップ無効**: Supabase の Authentication 設定で新規サインアップが
      無効になっている(招待制: ADR-005)。/admin/login からアカウント作成できない
- [ ] service_role キーがクライアントバンドルに含まれない(NEXT_PUBLIC_ でない)

### 予約カレンダー

- [ ] 日表示: 縦=時間軸・横=スタッフ列。予約ブロック・休憩・予約不可(斜線)が
      正しい位置に出る。前後ナビ・「今日」・日/週トグルが効く
- [ ] 週表示: 曜日列、定休日が斜線ハッチング、スタッフ色分けの凡例が出る
- [ ] **日付ジャンプ**: ヘッダーの日付ピッカーで1か月先など任意の日付へ一度で移動
      できる(日表示・週表示とも)。日付を消して空欄にしても勝手に遷移しない
- [ ] **定休日の視認性**: 週表示の定休日が一目で分かる(斜線+淡い下地+定休日バッジ)。
      定休日に予約がある場合も予約ブロックが前面で読める。ダークテーマでも破綻しない
- [ ] **週表示の重なり**: 別スタッフの予約を同じ日の同じ時間帯に入れると、
      週表示で左右に並んで**両方見える**(片方が隠れない)。3人分重ねると3等分になり、
      時間が接しているだけ(前の終了 == 次の開始)の2件は横幅いっぱいのまま。
      隣り合うカードの境目が輪郭で分かる
- [ ] **週表示のツールチップ**: 幅が狭くて文字が切れているカードにカーソルを乗せると、
      「11:00 山田様 / カット + カラー / 田中」が出る。カードのクリックは
      従来どおり予約詳細ダイアログが開く
- [ ] スマホ幅: 「タイムライン(1スタッフ切替)」と「リスト」に切り替わり、
      横スクロールが発生しない(レスポンシブ節とも重複)
- [ ] サイドバーのミニ集計(今日の予約件数・今月のLINEプッシュ n/200 バー)が
      実データと一致する

### 空き枠クリック → 代行登録ダイアログ

- [ ] **空き枠クリック(日表示)**: 日表示でスタッフ列の空いている時間帯をクリックすると、
      その場で代行登録ダイアログが開き、スタッフ・日付・時刻が初期入力済みになる。
      時刻は `salon_settings.slot_interval_minutes` の刻みに切り下がる
      (刻みを15分に変えると15分単位で入る = ハードコードしていない)
- [ ] **既存導線の非回帰**: 予約カードをクリックしたときは従来どおり
      予約詳細ダイアログが開く(代行登録ダイアログは開かない)。
      休憩・予約不可ブロックの上をクリックしたときは代行登録ダイアログでよい
- [ ] **ドラッグ移動**: ダイアログのヘッダーをつかんで移動できる。画面外へは
      出ず、ウィンドウをリサイズしても画面内に残る
- [ ] **非モーダル**: 背景が暗くならず、ダイアログを開いたまま背後のカレンダーを
      スクロール・日付移動できる(電話を受けながら空きを見る運用)
- [ ] **その場で反映**: 登録すると画面遷移せずダイアログが閉じ、登録した予約が
      そのままカレンダーに現れる
- [ ] **Escape・×で閉じる**。スマホ幅では画面下からのシート表示になり、
      ドラッグは無効(横スクロールが出ない)
- [ ] **定休日・過去**: 定休日/過去の時間帯をクリックして開いても、
      「定休日は登録できません」「過去の時間は登録できません」で登録できない。
      予約のない定休日はタイムライン自体が無く、クリックしても何も起きない
- [ ] **空き枠クリック(週表示)**: 週表示で日付列の空いている時間帯をクリックすると
      代行登録ダイアログが開き、**日付と時刻だけ**が初期入力され
      **スタッフは「選択してください」(未選択)**になる。時刻は日表示と同じく
      `salon_settings.slot_interval_minutes` の刻みに切り下がる
- [ ] **週表示の時間軸は正時始まり**: 週内に半端な時刻(例 9:15 開始)の予約が
      あっても、時間軸の目盛りと軸の上端・下端は正時のまま(営業時間そのものが
      正時でない店舗を除く)。この状態で空き時間をクリックすると、得られる時刻が
      空き枠一覧の時刻と一致する(9:15・9:45 のようにずれない)
- [ ] **週表示: スタッフを選ぶと空き情報が出る**: ダイアログ内でスタッフを選ぶと
      「この日の空き時間」一覧と空き判定メッセージが出る(誰が空いているかは
      スタッフを切り替えて確認できる)。未選択のまま登録しようとすると
      「スタッフを選択してください」がスタッフ欄に出て登録されない
- [ ] **週表示の非回帰**: 予約カードをクリックしたときは従来どおり予約詳細
      ダイアログのみが開く(代行登録ダイアログは開かない)。定休日の列も
      クリックで開くが「定休日は登録できません」で登録できない。
      営業日が1日もない週は「この週に営業日はありません。」のままで何も起きない

### 代行登録・店側変更・キャンセル

- [ ] **代行↔客側の往復**: 管理画面で代行登録(既存顧客検索・新規電話客のいずれも)
      → カレンダーに出る → **LIFFスタブ側の日時選択で同じ枠が「埋まり」表示**になる
- [ ] 顧客検索が名前・電話の部分一致で候補を出し、選択で確定・×で解除できる
- [ ] 代行登録の空き表示(「この枠は空いています。◯分確保できます。」/埋まり)が
      スタッフ・日時・メニューに追随する
- [ ] **空き枠でない理由が具体的に出る**: 「空き枠ではありません」で終わらず、
      その枠が作られなかった理由が出る。実データで一通り確認する
      - 勤務の無い曜日のスタッフ → 「◯◯さんはこの日の勤務がありません」
      - 始業前・終業後の時間 → 「勤務時間外です(◯:◯◯〜◯:◯◯)」
      - 休憩と重なる時間 → 「休憩時間です(◯:◯◯〜◯:◯◯)」
      - 他の予約と重なる時間 → 「この時間は他の予約と重なっています」
      - 閉店間際で所要時間が入らない → 「◯:◯◯の閉店までに◯分は確保できません」
      - 直前締切内 → 「直前すぎます(◯分前までに受付)」/ 受付期間の先 →
        「受付期間(◯日先まで)を超えています」
      - 刻みに合わない手入力(例 10:15)→ 「開始時刻が◯分刻みに合っていません」
      いずれも**時刻・分数・日数はDBの営業時間・勤務時間・`salon_settings` の値**で、
      設定を変えると文面も追随すること(ADR-007)。定休日・過去以外は登録ボタンが
      押せる(店側の上書き登録)
- [ ] **その日の空き時間一覧**: スタッフ・日付・メニューを選ぶと時刻ボタンが並び、
      埋まりは取り消し線+グレーで押せない。押すと時間欄に反映される。
      空き0件なら「この日に空き枠はありません」。定休日・受付期間外も0件になる
- [ ] **手入力の上書きは維持**: 一覧に無い時間(休憩中・勤務時間外)を時間欄へ
      手入力すると「他の予約と重なっています」等の注意付きで登録できる
- [ ] **変更モードの空き時間一覧**: 店側変更で開くと、自分の旧枠が「埋まり」でなく
      空きとして一覧に出る(excludeReservationId が効いている)
- [ ] 予約ブロックをタップ → 詳細ダイアログ(客名・連絡先・日時/担当・メニュー合計・
      ご要望・スタッフメモ)。ブロック(予約不可)・休憩には詳細が無い
      (日表示ではその上をタップすると代行登録ダイアログが開く。上の節を参照)
- [ ] **スタッフメモ**: 詳細から編集・保存すると customers.note に入り、
      **同じ客の別の予約詳細にも同じメモが出る**(顧客単位保存の確認)
- [ ] **変更はダイアログ内で完結**: 詳細の「変更」を押すと**ページ遷移せず**、
      カレンダー上に変更ダイアログ(非モーダル・ドラッグ可)が開く。顧客名は
      固定表示、メニュー・スタッフ・日時・メモが既存予約の値で埋まっている
- [ ] **変更ダイアログから詳細へ戻れる**: ヘッダーの「詳細に戻る」で同じ予約の
      詳細ダイアログに引き返せる(店側キャンセルの「戻る」と同じ体験)。
      Escape・× では閉じてカレンダーに戻る
- [ ] **変更ダイアログの初期位置**: 画面右寄りに開き、左端の時間目盛りと
      左側の列が見えている。ヘッダーをつかんで移動でき、画面外へ出ない。
      背景は暗くならず、背後のカレンダーを見ながら日時を調整できる
- [ ] **変更の反映**: 「この内容で変更」で遷移せずダイアログが閉じ、
      カレンダー上の予約がその場で新しい日時・担当へ移動する
- [ ] **ダイアログの排他**: 変更ダイアログを開いている間にカレンダーの空きを
      クリックしても代行登録ダイアログは開かない(入力が消えない)
- [ ] **ページ版の戻る導線**: `/admin/reservations/[id]/edit` と
      `/admin/reservations/new` を直URLで開くと上部に「カレンダーに戻る」があり、
      前者はその予約の日のカレンダーへ戻る
- [ ] **店側キャンセル**: 締切に関係なくキャンセルでき、枠が即座に空きに戻る
      (客側の日時選択で空きになる)。締切超過でも店側は操作できる
- [ ] **店側変更(UPDATE方式)**: 同じ予約を同枠のままメニュー変更・30分ずらしできる
      (自分の旧枠が「埋まり」にならない)。予約IDが変わらない(DBで確認)
- [ ] **変更の競合ロールバック**: 変更先の枠に別の予約を先に入れてから変更確定 →
      「その枠は埋まりました」になり、**元予約が担当・時間・メニューとも無傷で残る**
- [ ] **代行登録とLIFF予約の同時競合**: 管理画面の代行登録とLIFFの予約を同枠へ
      ほぼ同時に確定 → 片方だけ成功し、もう片方が23P01で弾かれる(EXCLUDE制約)

## 管理画面 設定系(M4b・未実装)

以下はM4bで実装する。実装時にこの節を上へ移し、チェック項目を具体化する。

- [ ] スタッフ権限でオーナー専用機能(スタッフ管理・メニュー管理)が操作できない
      (M4は両ロールとも全操作可のためロール差は未実装)
- [ ] メニュー・カテゴリ・営業時間・定休日・表示設定を管理画面から変更 →
      コード変更なしで客側の表示・空き枠計算に反映される(ADR-007)

## レスポンシブ(ADR-005)

- [ ] 管理画面をスマホ幅で開く → カレンダーが1スタッフ切替またはリスト表示に
      切り替わり、横スクロールが発生しない
- [ ] 客側の全画面がスマホ縦(LINE内ブラウザ)で崩れない

## データ設定(ADR-007)

- [ ] メニュー・カテゴリ・営業時間を管理画面から変更 → コード変更なしで
      客側の表示・空き枠計算に反映される
