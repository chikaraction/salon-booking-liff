# 美容室予約システム 画面モック作成指示

以下の仕様で、美容室のLINE予約システムの画面モックを作ってください。
目的は**実装前にオーナーに見せて操作イメージを確認する**ことです。
動くロジックは不要で、画面の見た目と遷移がわかれば十分です。

## プロジェクト概要(ADR要約)

- 美容室1店舗。スタッフはオーナー+バイトの2名
- 顧客は約200人、中心は40代以上。予約は月100件未満
- 予約の入口は既存のLINE公式アカウント。リッチメニューから予約画面(LIFFアプリ)を開く
- 客はLINEログインで自動認証(初回のみ名前・電話番号を入力)
- スタッフ指名あり。メニューごとに料金と所要時間が決まっており、所要時間分の枠を確保する
- 前日リマインドはLINEに自動送信
- 客は自分でキャンセル・変更可能(マイ予約から)
- 電話予約はオーナーが管理画面から代行登録
- 現在は手帳管理でダブルブッキングが発生しており、その解消が最重要目的

## デザイン方針

- **デザインシステム**: Tailwind CSSベースで、shadcn/ui風のコンポーネントスタイル(実装もTailwind + shadcn/uiで行うため、モックも同じ見た目の語彙で作る)
- **サイズ基準**: ベース文字サイズ16px以上、客側の主要ボタンは高さ48px以上。フォントはNoto Sans JP(比較用にLINE Seed JP版の画面も1枚あると良い)
- **テーマカラー**: 1色+ニュートラルの落ち着いた配色。候補を2〜3案作ってオーナーに選んでもらう
- **客側**: スマホ縦画面前提(LIFFはLINEアプリ内ブラウザで開く)。客層が40代以上中心なので、文字は大きめ・ボタンは押しやすく・1画面1操作を徹底。選択済みの内容(メニュー・スタッフ・日時)を画面上部に常に表示して迷子にさせない
- **店側**: レスポンシブ対応必須。基本はPC/タブレット横画面で一覧性重視だが、旅行先などスマホで確認するケースがあるため、スマホ幅では予約カレンダーを「1日×スタッフ切替表示」または「予約リスト表示」に切り替えるなど、閲覧・簡単な操作ができるレイアウトにする(スマホ版のモックも1枚作る)
- トーン: 美容室らしい清潔感と落ち着き。派手な装飾より余白と読みやすさ優先
- 店名・メニュー名・料金はダミーでよい(例: カット ¥4,400/60分、カラー ¥8,800/120分、パーマ、カット+カラー)

## 客側画面(LIFF・スマホ)

1. **メニュー選択** — カテゴリ(カット/カラー/パーマ/トリートメントなど)ごとにグループ分けして表示。各メニューは名前・料金・所要時間付きのカードで、**複数選択可**(例: カット+カラー)。選択中の合計料金・合計所要時間を画面下部に固定表示し、「次へ」ボタンもそこに置く
2. **スタッフ選択** — オーナー/スタッフ/「どちらでも」の3択。顔写真枠と一言紹介付き
3. **日時選択** — カレンダーで日付選択 → その日の空き時間をボタン一覧で表示。埋まっている枠は表示しない(またはグレーアウト)
4. **予約確認** — メニュー・スタッフ・日時・合計料金・所要時間を一覧で最終確認。「予約を確定する」ボタン
5. **予約完了** — 完了メッセージと予約内容。「マイ予約で確認できます」の案内
6. **初回情報入力** — 名前・電話番号の2項目のみ(初回予約時に確認画面の前に挟まる)
7. **マイ予約** — 今後の予約一覧。各予約に「変更」「キャンセル」ボタン。キャンセルは確認ダイアログ付き

## 店側画面(管理画面・PC/タブレット)

1. **ログイン** — メール+パスワード
2. **予約カレンダー(メイン画面)** — 日表示: 縦軸が時間、横軸がスタッフ2名の2列。予約がブロックで表示され、タップで詳細。週表示への切替あり
3. **予約詳細** — 客名・連絡先・メニュー・料金・メモ。「変更」「店側でキャンセル」ボタン(変更は日時・スタッフ・メニューを編集できる画面へ)
4. **代行登録** — 電話予約用。客名・電話番号・メニュー・スタッフ・日時を入力して登録。既存顧客の検索付き
5. **スタッフ設定** — 勤務曜日・時間、休憩、臨時休の設定
6. **メニュー管理** — メニューの追加・編集(名前・料金・所要時間)
7. **ダッシュボード小物** — 今日の予約件数、今月のLINEプッシュ送信数(200通の無料枠に対する使用量バー)

## 遷移

- 客側: 1→2→3→(初回のみ6)→4→5。マイ予約はリッチメニューの別ボタンから直接開く
- 店側: ログイン→予約カレンダーがホーム。他画面はサイドメニューから

## 作ってほしい順番

まず客側の1〜5(予約の基本フロー)を通しで。次に店側の予約カレンダーと代行登録。残りはその後で。
