# 操作マニュアル

美容室の来店予約システムの使い方です。お客様は LINE 公式アカウントから予約し、お店は Web の管理画面で予約を管理します。

{: .note }
このシステムは参考実装として公開しているもので、実際の店舗では運用していません。画面に出てくる店名・スタッフ名・メニュー・料金・お客様の名前は、すべて架空のものです。

## 誰がどの画面を使うか

| 使う人   | 画面                                            | 開き方                                           |
| -------- | ----------------------------------------------- | ------------------------------------------------ |
| お客様   | 予約画面・マイ予約(LINE の中で開く LIFF アプリ) | 店の LINE 公式アカウントのリッチメニューから開く |
| オーナー | 管理画面(すべての操作)                          | パソコン・タブレット・スマホのブラウザで開く     |
| スタッフ | 管理画面(予約の操作のみ。設定は変えられない)    | 同上                                             |

## 予約の流れ

1. お客様が LINE のリッチメニューから予約画面を開き、メニュー・スタッフ・日時を選んで予約します。
2. お店の管理画面の予約カレンダーに、すぐに予約が表示されます。
3. 予約の前日に、お客様の LINE へリマインドが届きます。
4. お客様は「マイ予約」から、締切までは自分で変更・キャンセルできます。締切を過ぎたら、お店に直接連絡してもらいます。
5. 電話で受けた予約は、お店が管理画面から代行登録します。

同じスタッフの同じ時間帯に 2 件の予約が入ることはありません。2 人のお客様が同時に同じ枠を予約しようとしても、先に確定した 1 件だけが入り、もう 1 人には「その枠は埋まりました」と表示されます。
