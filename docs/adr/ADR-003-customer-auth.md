# ADR-003: 顧客認証(LINEログイン/LIFF)【改訂v2】

- ステータス: 承認済み
- 日付: 2026-07-15(v1: ゲスト予約+メールリンク案を置き換え)

## 改訂の経緯

v1では「LINEを使わない客の排除を避ける」ためゲスト予約を採用したが、電話予約客はオーナーが代行登録する運用に決まったため、Web予約する客=LINE利用者と割り切れるようになった。

## Decision(決定)

- 予約画面は**LIFFアプリ**として実装し、**LINEログインで自動認証**する(客はログイン操作を意識しない。LINEで開けば本人特定済み)
- 顧客はLINEの`userId`で識別。初回予約時に名前・電話番号を入力してもらい顧客レコードを作成、2回目以降は入力不要
- **キャンセル・変更**はLIFF内の「マイ予約」から客自身が操作
- 電話予約の客は、オーナーが管理画面で顧客レコード(LINE紐付けなし)を作成して代行登録。通知・リマインドはオーナーが従来通り口頭・手動で対応

## 理由

- 全顧客が友だち登録済みなので、LINEログインが最も摩擦の少ない導線。パスワードもメールアドレスも不要
- 40代以上の客層でも「いつものLINEのメニューから押すだけ」なら操作ハードルが低い
- リピーター(顧客の大半)は2回目以降、メニューと日時を選ぶだけで予約完了できる

## 検討した代替案

- **ゲスト予約+署名付きメールリンク(v1案)**: LINE運用と分断され、リピーター識別もできない。→ 却下
- **会員登録(メール+パスワード)**: 客層・規模に対して過剰。→ 却下

## Consequences(影響)

- 良い点: 予約履歴が顧客ごとに自動で蓄積され、オーナーが来店履歴を確認できる(手帳の置き換え)。
- 注意点: LIFF/LINEログインの初期設定が必要。同一客が「LINE予約」と「電話予約」の両方を使う場合、顧客レコードが二重になる可能性 → 管理画面に顧客の統合(マージ)機能を将来追加できる余地を残す。
