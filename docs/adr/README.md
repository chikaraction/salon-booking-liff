# ADR: 美容室 来店予約システム

## プロジェクト概要(インタビュー結果の要約)

| 項目          | 内容                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------- |
| 対象          | 美容室(1店舗)の来店予約                                                                       |
| スタッフ      | オーナー+バイト1名(計2名)                                                         |
| 顧客          | 約200人。中高年が中心 |
| 予約単位      | スタッフ指名あり                                                                              |
| 予約件数      | 月100件未満の見込み                                                                           |
| 現状          | LINE公式アカウントでやり取り+手帳で管理。**ダブルブッキングが複数回発生** → 解消が最重要目的  |
| 電話・SMS予約 | 少数。今後もオーナーが管理画面で代行登録する運用                                              |
| 通知          | 予約確認・前日リマインドが必須                                                                |
| キャンセル    | 客が自分でキャンセル・変更できる                                                              |
| 開発体制      | AI主導(発注者は指示中心)                                                                      |
| 運用コスト    | 無料〜月数百円                                                                                |

## ADRの読み方

各ADRは「状況(Context)→ 決定(Decision)→ 理由と代替案 → 影響(Consequences)」の形式。
承認済みADRを覆す場合は新しいADRで置き換え、旧版は履歴として残す(承認前の改訂はv2などと明記して上書き可)。
