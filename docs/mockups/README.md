# Handoff: 美容室 LINE予約システム（hair & make LUCE）

## Overview
美容室1店舗（スタッフ2名：オーナー田中／スタッフ佐藤、顧客約200人・40代以上中心、予約月100件未満）向けのLINE予約システム。
- 客側：LINE公式アカウントのリッチメニューから開く LIFF アプリ（スマホ縦）。LINEログインで自動認証、初回のみ名前・電話番号入力。
- 店側：管理画面（PC/タブレット横が基本、スマホ幅にもレスポンシブ対応）。
- 最重要目的：手帳管理で起きているダブルブッキングの解消（所要時間分の枠を確保）。

## About the Design Files
このフォルダのHTMLは **デザインリファレンス（HTMLで作ったモック）** であり、そのまま本番に使うコードではありません。
実装は **Tailwind CSS + shadcn/ui（React）** で、これらのデザインを再現してください。ロジックはモック内では動きません（見た目と遷移の確認用）。

- `美容室LINE予約システムモック.html` … ブラウザで直接開ける単一ファイル版（オフライン可）。目視確認用。
- `mock.dc.html` … ソース版。全画面のマークアップ（インラインスタイル）を読めます。数値の参照はこちらから。

## Fidelity
**High-fidelity**。色・タイポ・余白・角丸はこのモックに合わせてください。ただしコンポーネントは shadcn/ui の Button / Card / Input / Dialog / Select / Switch / Tabs(ToggleGroup) 等に置き換えて実装すること。

## Screens — 客側（LIFF・スマホ縦 375px 基準）
共通：上部ヘッダー（白・下線）に `STEP n / 4`、画面タイトル、**選択済み内容のチップ（メニュー・スタッフ）を常時表示**。下部に固定アクションバー（戻る 96px + 主ボタン flex:1）。1画面1操作。

1. **メニュー選択**：カテゴリ見出し（accentDark 13px/700）＋説明（11px）＋メニューカード（名前・所要時間・税込料金・選択丸）。**複数選択可**。下部固定バーに「選択中 n件・合計 約x分」「合計金額」「次へ（スタッフ選択）」。冒頭に「※ 表示価格は税込です」。
2. **スタッフ選択**：オーナー／スタッフ／どちらでも の3カード（64px丸の顔写真枠・名前・一言紹介）。
3. **日時選択**：月カレンダー（7列、選択日 accent塗り、定休日/過去日はグレー）→ 「◯月◯日（曜）の空き時間」3列の時間ボタン。埋まっている枠はグレー＋取り消し線（または非表示）。所要時間分を確保できる開始時刻のみ有効。
4. **初回情報入力**（初回のみ、確認の前）：お名前・電話番号の2項目＋「LINEアカウントと紐づくため次回以降は不要」案内。
5. **予約確認**：メニュー（各料金）・スタッフ・日時＋所要時間・合計（tint背景）。**ご要望・ご相談（任意）テキストエリア** → 店側予約詳細の「お客様からのご要望」に表示。前日LINEリマインドの案内。「予約を確定する」。
6. **予約完了**：✓ 84px丸、「ご予約が完了しました」、予約内容カード、「変更・キャンセルはマイ予約から」案内、「マイ予約を見る」。
7. **マイ予約**（リッチメニューから直接）：今後の予約カード（ステータスチップ・日時・メニュー/スタッフ・料金）＋「変更」「キャンセル」(48px)。キャンセルは**ボトムシート確認ダイアログ**（キャンセルする=danger塗り／戻る）。

遷移：1→2→3→(初回のみ初回情報入力)→確認→完了。マイ予約は別入口。

## Screens — 店側（管理画面）
共通レイアウト：**左サイドバー 214px（固定）＋右コンテンツ**。各設定画面はモーダルではなく右側コンテンツの差し替え（「戻る」バー不要）。
サイドバー：予約カレンダー / 代行登録 / スタッフ設定 / メニュー管理 / 定休日・祝日 / 表示設定。下部にダッシュボード小物（今日 or 今週の予約件数、今月のLINEプッシュ使用量バー 128/200）。

- **A. ログイン**：メール＋パスワード、ログインボタン。
- **B. 予約カレンダー・日表示（ホーム）**：ツールバー（前後・日付・「今日」チップ・日/週切替）。縦=時間（9:00–19:00、1時間64px）、横=スタッフ2列。予約ブロック（左4px色帯・客名・メニュー・所要）。休憩ブロック。ブロッククリック→予約詳細。
- **B-2. 週表示**：同じサイドバー。7日列（1時間40px）、スタッフは色で区別（凡例あり）。定休日は斜線パターン＋「定休日」。
- **C. 予約詳細**（カレンダー上のポップオーバー/ダイアログ、✕で閉じる）：客名・連絡先・日時/担当・メニュー/料金・**お客様からのご要望（予約時入力・tint背景）**・**スタッフメモ（店内用・編集可）**。「変更」（日時・スタッフ・メニュー編集画面へ）「店側でキャンセル」。
- **D. 代行登録**（電話予約）：既存顧客インクリメンタル検索（候補リスト）・メニュー・スタッフ・日付・時間・空き判定メッセージ（「この枠は空いています。x分確保できます」）・**メモ（任意・店内用）**・「この内容で登録」。
- **E. スタッフ設定**：勤務曜日トグル、開始/終了/休憩、臨時休の追加。
- **E-2. 定休日・祝日**：毎週の定休曜日（例：水）、**特定週の定休（曜日セレクト＋第1〜第5 の複数選択、例：第3日曜）**、祝日自動休業スイッチ、臨時休業・連休リスト。休業日は客側に予約枠を出さない。
- **F. メニュー管理**：カテゴリごとの表（⠿ドラッグ・名前・税込料金・所要時間・編集）。**行のドラッグで表示順変更**。ヘッダーに「カテゴリを編集」「＋ 新規メニュー」。
  - **カテゴリ編集ダイアログ**：⠿並べ替え・名称入力・✕削除・「＋ カテゴリを追加」（押すと末尾に空の入力行がフォーカス状態で増える）・キャンセル/保存。
- **F-2. 表示設定**：テーマカラー（A/B/C＋カスタム色、濃淡自動生成）、フォント（Noto Sans JP / LINE Seed JP）、保存。
- **G. ダッシュボード小物**：今日の予約件数（スタッフ別内訳）、今月の予約件数、LINEプッシュ送信数（無料枠200通に対する使用量バー＋残り）。

### スマホ幅（店側）
- **H. 1日×スタッフ切替**：日付ナビ＋スタッフ切替（田中/佐藤）＋時間軸1列。空き・重なり判断向け。
- **I. 予約リスト**：時刻・客名・メニュー/担当のカード一覧。移動中の素早い確認向け。
- ブレークポイント例：`md` 未満でサイドバー→ハンバーガー/下部ナビ、カレンダー→H/I。

## State / Data model（目安）
- Customer(line_user_id, name, phone), Staff(name, role, intro, photo, work_days, start, end, break), Category(name, sort_order), Menu(category_id, name, price_min, price_max, is_addon, duration_min, sort_order)
- Reservation(customer_id, staff_id, start_at, end_at, menus[], total_price, customer_request, staff_memo, source: line|phone, status)
- Holiday rules：weekly(曜日)、nth_weekday(曜日, [1..5])、national_holiday(bool)、specific dates/ranges
- Settings(theme_key, custom_accent, font)
- 空き枠計算：スタッフ勤務 − 休憩 − 定休/臨時休 − 既存予約 に対して所要時間が収まる開始時刻のみ。予約確定時はトランザクション/排他でダブルブッキング防止。
