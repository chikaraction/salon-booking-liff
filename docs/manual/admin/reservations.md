# 予約の登録・変更・キャンセル

電話などで受けた予約は、お店が管理画面から登録します(代行登録)。お客様の予約の変更やキャンセルも、管理画面からできます。

## 電話予約を代行登録する

![電話予約の代行登録]({{ site.baseurl }}/manual/images/admin-05-proxy.png)

サイドバーの「代行登録」を開きます。予約カレンダーの空いているところを押しても開けます。

1. **お客様名**: 名前か電話番号の一部を入れると、登録済みのお客様が候補に出ます。選ぶと「既存のお客様として登録します」と表示されます。初めてのお客様なら、名前をそのまま入れ、電話番号(任意)も入れます。
2. **メニュー**: 当てはまるものにチェックを入れます(複数可)。合計の金額と所要時間が出ます。
3. **スタッフ**: 担当を選びます。
4. **日付・時間**: 日付を選ぶと「この日の空き時間」が並ぶので、押して選びます。一覧に無い時刻も、時間の欄に手で入れれば登録できます。
5. **ご要望・ご相談**(任意): 予約詳細の「ご要望・ご相談」に表示されます。お客様がマイ予約から変更するときに、お客様にも見えます。店内だけのメモは、予約詳細の「スタッフメモ」に書きます。
6. 「この内容で登録」を押します。

{: .warning }
同じスタッフの同じ時間に、すでに予約が入っていると登録できません。お客様の LINE からの予約とぶつかったときも、先に確定したほうだけが残ります。

## 予約を変更する

1. 予約カレンダーで予約を押し、予約詳細の「**変更**」を押します。
2. 「予約の変更」が開きます。メニュー・スタッフ・日時・ご要望を変えられます。お客様は変えられません。
3. 「この内容で変更」を押します。

変更すると、元の時間は空きに戻ります。お店からの変更には、お客様の[変更締切]({{ site.baseurl }}/admin/settings/salon/)はかかりません。

## 店側でキャンセルする

1. 予約詳細の「**店側でキャンセル**」を押します。
2. 「この予約をキャンセルしますか?」と出るので、「キャンセルする」を押します。

キャンセルすると枠が空きに戻り、カレンダーから予約が消えます。お店からのキャンセルには、お客様のキャンセル締切はかかりません。

{: .note }
お店が変更・キャンセルしても、お客様の LINE には自動でお知らせが届きません。必要に応じてお客様に連絡してください。
