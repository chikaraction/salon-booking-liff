# お店の操作(管理画面)

管理画面はパソコン・タブレット・スマホのブラウザで使います。予約の確認と電話予約の登録はオーナーもスタッフもでき、営業日やメニューなどの設定はオーナーだけが変えられます。

| 操作                                                 | オーナー | スタッフ |
| ---------------------------------------------------- | -------- | -------- |
| 予約カレンダーを見る・予約の詳細を開く               | ○        | ○        |
| 電話予約の代行登録・予約の変更・店側でのキャンセル   | ○        | ○        |
| スタッフメモを書く                                   | ○        | ○        |
| ダッシュボードを見る                                 | ○        | ○        |
| 設定(営業日・スタッフ・メニュー・店舗・表示)を変える | ○        | ×        |

スタッフでログインすると、サイドバーに「設定」の項目が出ません。設定画面の URL を直接開くと「この操作にはオーナー権限が必要です」と表示されます。
