# ダッシュボード

![ダッシュボード]({{ '/manual/images/admin-06-dashboard.png' | relative_url }})

サイドバーの「ダッシュボード」で開きます。

| 項目                       | 内容                                                |
| -------------------------- | --------------------------------------------------- |
| 今日の予約件数             | 今日の予約の件数と、スタッフごとの内訳              |
| 今月の予約                 | 今月の予約の件数と、先月との差                      |
| 今月の LINE プッシュ送信数 | 前日リマインドで使った数と、無料枠(月 200 通)の残り |

LINE 公式アカウントの無料プランでは、お店から送るメッセージ(プッシュ)は月 200 通までです。このシステムでプッシュを使うのは前日リマインドだけで、1 件の予約につき 1 通です。今月の送信数が **150 通を超えると**、サイドバーの送信数の下に「150通を超えました」と表示されます(200 通を超えると「無料枠を超えました」)。予約確認の返信は無料なので数えません。

今日の予約件数と今月の送信数は、サイドバーの下にも小さく表示されます。
