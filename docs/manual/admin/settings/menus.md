# メニュー

![メニュー管理]({{ site.baseurl }}/manual/images/admin-09-menus.png)

メニューはカテゴリ(カット、カラーなど)ごとに並びます。ここでの並び順が、お客様の予約画面の並び順になります。

## メニューを追加・編集する

![メニューの編集]({{ site.baseurl }}/manual/images/admin-10-menu-edit.png)

1. 新しいメニューは「新規メニュー」、登録済みのメニューは行の「編集」を押します。
2. メニュー名・カテゴリ・料金(税込)・所要時間(分)を入れます。
3. 「保存する」を押します。

所要時間は、お客様の予約画面で空き枠を計算するのに使います。予約は「選んだメニューの所要時間の合計」の分だけ枠を取ります。

{: .warning }
メニューは削除できません。過去の予約が残っているためです。使わなくなったメニューは「お客様の予約画面に表示する」をオフにしてください。オフにすると予約画面に出なくなり、過去の予約はそのまま残ります。一覧では「非表示」と表示されます。

## 並び順を変える

行の左の「⠿」をつかんで上下にドラッグします。キーボードでは、⠿ にフォーカスしてスペースキーを押し、矢印キーで動かして、もう一度スペースキーで確定します。

## カテゴリを編集する

![カテゴリの編集]({{ site.baseurl }}/manual/images/admin-11-category-edit.png)

「カテゴリを編集」を押すと、カテゴリの一覧が開きます。

- 名前を書き換える、⠿ をドラッグして並べ替える、「カテゴリを追加」で増やす、「×」で削除する、ができます。
- 終わったら「保存する」を押します。
- メニューが入っているカテゴリは削除できません。先に、そのメニューを別のカテゴリに移してください。
