# スタッフ

![スタッフの設定]({{ site.baseurl }}/manual/images/admin-08-staff.png)

スタッフごとに、勤務する曜日・時間・休憩と、臨時休を設定します。設定はお客様の予約画面の空き枠にそのまま反映されます。

## スタッフを選ぶ・追加する

- 上の「スタッフを選ぶ」で、設定するスタッフを押します。
- 新しいスタッフは「スタッフを追加」から登録します。

## スタッフ情報

「スタッフ情報を編集」で、次の項目を変えられます。

| 項目     | 内容                                                          |
| -------- | ------------------------------------------------------------- |
| 名前     | お客様の予約画面と管理画面に出る名前                          |
| ロール   | オーナーかスタッフか([権限の違い]({{ site.baseurl }}/admin/)) |
| 表示順   | 並び順(小さいほど先)                                          |
| 状態     | 有効か無効か                                                  |
| 自己紹介 | お客様がスタッフを選ぶ画面に出る一言(任意)                    |

{: .warning }
スタッフは削除できません。過去の予約が残っているためです。辞めたスタッフは「無効」にしてください。無効にすると、予約画面の指名候補と空き枠から外れ、過去の予約はそのまま残ります。

## 勤務曜日・時間・休憩

1. 「勤務曜日・時間」で、勤務する曜日を押して選びます。
2. 曜日ごとに開始・終了と、休憩の開始・終了を入れます。休憩がなければ両方空欄にします。
3. 全部の曜日を同じ時刻にするときは「(曜日)と同じ時刻をすべての勤務日に適用」を押すと便利です。
4. 「保存する」を押します。

スタッフの勤務は、毎週同じ曜日・同じ時間のパターンで登録します。週や月ごとのシフト表を作る機能はありません。

## 臨時休

スタッフ 1 人だけが休む日を登録します。

1. 「臨時休を追加」の「追加」を押します。
2. 日付(または範囲)を選び、「終日」か「時間帯を指定」を選びます。
   - **終日**: その日の勤務時間をすべて休みにします。
   - **時間帯を指定**: 指定した時間だけ休みにします。勤務のない曜日は時間帯を指定してください。
3. 「追加」を押します。

## 管理画面へのログイン

この画面で作れるのはスタッフの情報と勤務だけで、管理画面にログインするアカウントは作られません。施術だけを担当し管理画面を使わないスタッフは、この画面の設定だけで済みます。ログインが必要なスタッフのアカウントは、システムの管理者が作ります。
