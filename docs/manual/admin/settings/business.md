# 営業日・営業時間

![営業日・営業時間の設定]({{ site.baseurl }}/manual/images/admin-07-business.png)

休業日を登録すると、その日はお客様の予約画面で選べなくなり、予約を受け付けません。

## 毎週の定休日と営業時間

1. 「毎週の定休日」で、毎週休む曜日を押して選びます(もう一度押すと営業日に戻ります)。
2. 「曜日ごとの営業時間」で、営業する曜日の開店時刻と閉店時刻を入れます。定休の曜日は入力できません。
3. 「保存する」を押します。

## 特定の週だけの定休日

「毎月第 3 日曜日は休み」のような決まりを登録します。

1. 「特定の週だけの定休日」の「追加」を押します。
2. 曜日を選び、「第 1」〜「第 5」から休む週を押して選びます(複数可)。
3. 「保存する」を押します。

削除するときは、行の右のごみ箱のボタンを押してから保存します。

## 祝日を休業にする

「祝日を休業にする」をオンにすると、日本の祝日を自動で休業にします。休業になる祝日は、下の「臨時休業・指定日」の一覧に並びます。

## 臨時休業・指定日

夏季休業や、定休日だけど営業する日などを登録します。

1. 「日付を追加」を押します。
2. 開始日と終了日を入れます(1 日だけなら同じ日)。
3. 区分を選びます。
   - **休業**: その期間を休業にします(一覧では「臨時休」と表示されます)。
   - **臨時営業**: 休業日(定休日・祝日)でも営業します。営業時間は臨時営業のときだけ入れられ、定休の曜日を含むときは必須です。
4. ラベル(任意。例: 夏季休業)を入れ、「登録する」を押します。

登録を削除するときは、一覧の行の削除ボタンを押します。

{: .note }
スタッフ 1 人だけの休みは、ここではなく[スタッフ]({{ site.baseurl }}/admin/settings/staff/)の「臨時休」で登録します。
