# 表示設定

![表示設定]({{ site.baseurl }}/manual/images/admin-13-display.png)

お客様の画面と管理画面の、色とフォントを決めます。

- **テーマカラー**: 「セージグリーン」「モーヴ」「スレートブルー」から選びます。今使っている色には「採用中」と出ます。好きな色を指定する「カスタム」は、まだ使えません。
- **フォント**: 「Noto Sans JP」と「LINE Seed JP」から選びます。

選んだら「保存する」を押します。
