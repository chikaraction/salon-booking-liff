# ログインと画面の見方

## ログイン

![ログイン画面]({{ site.baseurl }}/manual/images/admin-01-login.png)

管理画面(`/admin`)を開き、メールアドレスとパスワードを入れて「ログイン」を押します。

{: .note }
ログインのアカウントは、システムの管理者(開発者)が作ります。管理画面から新しいアカウントを作ることはできません。作り方は[セットアップの手順](https://github.com/chikaraction/salon-booking-liff/blob/main/docs/setup.md)にあります。

## 画面の見方

![予約カレンダー(日表示)]({{ site.baseurl }}/manual/images/admin-02-calendar-day.png)

- **左のサイドバー**: 上に店名、その下に「予約カレンダー」「代行登録」「ダッシュボード」と、オーナーには「設定」の各項目が並びます。
- **サイドバーの下**: 今日の予約件数と、今月の LINE のプッシュ送信数が出ます。
- **ログアウト**: サイドバーのいちばん下にあります。

## スマホで使うとき

![スマホ幅の予約カレンダー]({{ site.baseurl }}/manual/images/admin-14-phone-calendar.png){: width="320" }

スマホの幅では、サイドバーは右上の「≡」ボタンで開きます。予約カレンダーの使い方は[予約カレンダー]({{ site.baseurl }}/admin/calendar/)を見てください。
