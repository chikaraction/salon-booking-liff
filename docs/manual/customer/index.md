# お客様の操作

お客様は、お店の LINE 公式アカウントのリッチメニューから予約画面とマイ予約を開きます。LINE アカウントでそのままログインするので、パスワードは要りません。

- [予約する]({{ site.baseurl }}/customer/booking/)
- [予約を確認・変更・キャンセルする]({{ site.baseurl }}/customer/my-reservations/)
- [LINE に届くメッセージ]({{ site.baseurl }}/customer/notifications/)

{: .note }
予約画面とマイ予約は、LINE アプリの中でだけ使えます。普通のブラウザで開くと「アプリから開いてください」と表示されます。
