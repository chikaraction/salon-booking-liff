# お客様の操作

お客様は、お店の LINE 公式アカウントのリッチメニューから予約画面とマイ予約を開きます。LINE アカウントでそのままログインするので、パスワードは要りません。

- [予約する]({{ '/customer/booking/' | relative_url }})
- [予約を確認・変更・キャンセルする]({{ '/customer/my-reservations/' | relative_url }})
- [LINE に届くメッセージ]({{ '/customer/notifications/' | relative_url }})

{: .note }
予約画面とマイ予約は、LINE アプリの中でだけ使えます。普通のブラウザで開くと「アプリから開いてください」と表示されます。
