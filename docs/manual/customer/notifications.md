# LINE に届くメッセージ

予約に関するお知らせは、お店の LINE 公式アカウントのトークに届きます。

## 予約確認(予約・変更したとき)

予約を確定すると、お客様の LINE から「予約を確定しました」(変更のときは「予約を変更しました」)という定型文がお店に送られ、お店から次のような返信が自動で届きます。

```text
ご予約ありがとうございます。
以下の内容で承りました。

日時: 11月12日(木)13:30〜
メニュー: カット + トリートメント
担当: オーナー
合計: ¥7,700(約90分)

変更・キャンセルはリッチメニューの「マイ予約」からどうぞ。
https://liff.line.me/(LIFF ID)/my
サンプルサロン
```

{: .note }
お客様の操作に対する返信なので、LINE の無料メッセージ数(月 200 通)を消費しません。

## 前日のリマインド

予約の前日、お店が決めた時刻(既定は 18:00)以降に、次のようなメッセージが届きます。

```text
【明日のご予約】
日時: 11月12日(木)13:30〜
メニュー: カット + トリートメント
担当: オーナー

ご来店をお待ちしております。
ご都合が変わった場合は「マイ予約」から変更・キャンセルできます。
https://liff.line.me/(LIFF ID)/my
サンプルサロン
```

最後の 2 行はマイ予約を開くリンクと店名です。リマインドは 1 件の予約につき 1 通です。送信時刻はお店が[店舗・予約設定]({{ '/admin/settings/salon/' | relative_url }})で変えられます。22:00 以降は送りません。
