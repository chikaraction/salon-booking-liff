# よくある質問

## お客様の予約画面に、ある日・ある時間の枠が出ない

次のどれかに当てはまっていないか確かめてください。

| 確かめるところ                                                  | 枠が出ない理由                                 |
| --------------------------------------------------------------- | ---------------------------------------------- |
| [営業日・営業時間]({{ site.baseurl }}/admin/settings/business/) | 定休日・祝日・臨時休業、または営業時間の外     |
| [スタッフ]({{ site.baseurl }}/admin/settings/staff/)            | そのスタッフの勤務曜日でない、休憩中、臨時休   |
| [店舗・予約設定]({{ site.baseurl }}/admin/settings/salon/)      | 受付期間より先の日、または直前締切を過ぎた時刻 |
| [予約カレンダー]({{ site.baseurl }}/admin/calendar/)            | すでに予約が入っている                         |
| 選んだメニュー                                                  | 所要時間の合計が、空いている時間に収まらない   |

所要時間の長いメニューを選ぶほど、選べる開始時刻は減ります。

## お客様が「変更・キャンセルはお店に直接ご連絡ください」と言われた

予約の開始時刻がキャンセル締切(既定は 1 時間前)を過ぎています。お店が管理画面から[変更・キャンセル]({{ site.baseurl }}/admin/reservations/)してください。お店の操作には締切がかかりません。

## お客様が新しい予約を入れられない

1 人が持てる「これからの予約」には上限があります(既定は 3 件)。上限に達していると「これからのご予約が上限に達しているため、新しいご予約をお受けできません」と表示されます。不要な予約がないか、お客様にマイ予約で確かめてもらってください。電話で受けた予約を、お店が代行登録するときには上限はかかりません。

## 予約画面に「アプリから開いてください」と出る

予約画面とマイ予約は、LINE アプリの中でだけ使えます。LINE のトーク画面のリッチメニューから開き直してください。

## スタッフが辞めた

スタッフは削除できないので、[スタッフ]({{ site.baseurl }}/admin/settings/staff/)の「スタッフ情報を編集」で「無効」にします。予約の指名候補と空き枠から外れ、過去の予約は残ります。そのスタッフが管理画面にログインしていた場合は、システムの管理者にログインのアカウントの削除を頼んでください。

## スタッフでログインすると設定が出ない

設定を変えられるのはオーナーだけです。[権限の違い]({{ site.baseurl }}/admin/)を見てください。

## ログインできるのに予約カレンダーが空で、設定も出ない

ログインのアカウントが、スタッフの登録と紐付いていません。システムの管理者に紐付けを頼んでください(手順は[セットアップとデプロイ](https://github.com/chikaraction/salon-booking-liff/blob/main/docs/setup.md)の「管理画面にログインさせる」)。
